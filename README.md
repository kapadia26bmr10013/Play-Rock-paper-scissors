# Play-Rock-paper-scissors
A lightweight, interactive command-line implementation of the classic Rock, Paper, Scissors game built with Python. Test your luck against the computer in a quick match or play a multi-round series to claim ultimate victory!

✨Features

3 AI Difficulty Levels:

Easy: Random computer selections.
Medium: Pattern-matching AI that adapts to your most frequently used choices.
Hard: A mixed AI strategy combining adaptive pattern-tracking with anti-predictability logic.
Player Profiles & Statistics: Tracks wins, losses, ties, total games played, win percentages, and current/best winning streaks.
Match History: Timestamped logs for every round played during the session.
Achievement System: Unlocks milestones based on total wins, streaks, and total games played.
Zero External Dependencies: Built entirely using Python Standard Library (random, datetime).
